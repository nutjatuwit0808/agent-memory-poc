# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(budget-pacer): sync เวลาให้ตรงกันข้าม pod ป้องกัน overspend`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-ad-bidding/branch-naming]]
