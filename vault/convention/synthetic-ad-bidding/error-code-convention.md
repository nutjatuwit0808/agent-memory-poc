# Error Code Convention

## รูปแบบ

`ADPULSE_<DOMAIN>_<REASON>` เช่น `ADPULSE_BID_TIMEOUT`, `ADPULSE_BUDGET_EXHAUSTED` ตัวพิมพ์ใหญ่ทั้งหมด

## หมวดที่ใช้บ่อย

`ADPULSE_FRAUD_BLOCKED`, `ADPULSE_CREATIVE_NOT_APPROVED`, `ADPULSE_FLOOR_PRICE_REJECTED` — ดูรายชื่อเต็มที่ [[convention/synthetic-ad-bidding/api-response-format]]
