# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(channel-exporter): แก้ retry interval สำหรับ external channel ที่มี rate limit ต่ำ`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-customer-segmentation/branch-naming]]
