# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(plan-manager): เพิ่ม idempotency key กันเปลี่ยนแพลนซ้ำ`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-subscription-billing/branch-naming]]
