# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(assessment-engine): enforce server-side timer validation ป้องกัน bypass`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-e-learning/branch-naming]]
