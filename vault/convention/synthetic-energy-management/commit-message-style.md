# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(demand-response-controller): แก้ cooldown bypass ข้าม event ประเภทต่างๆ`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-energy-management/branch-naming]]
