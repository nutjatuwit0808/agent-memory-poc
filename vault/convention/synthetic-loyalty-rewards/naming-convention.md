# Naming Convention

## ตัวแปรและฟังก์ชัน

`camelCase` เช่น `creditPoints`, `evaluateTierChange` — ฟังก์ชัน async ขึ้นต้นด้วยคำกริยา action ชัดเจน ไม่เติม `Async` ต่อท้าย

## Identifier ของ member

`accountId` เป็น UUID ภายใน ต่างจาก `memberId` ที่แสดงต่อสมาชิก — ห้ามใช้แทนกันในโค้ด ต้องแยก mapping ชัดเจนตลอด
