# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(redemption-engine): ใช้ atomic compare-and-swap ป้องกัน race condition`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` ตรงกับ prefix ของ [[convention/synthetic-loyalty-rewards/branch-naming]]
