# Error Code Convention

## รูปแบบ

`WAVE_<DOMAIN>_<REASON>` เช่น `WAVE_SEGMENT_STALE`, `WAVE_CONSENT_OPTED_OUT` ตัวพิมพ์ใหญ่ทั้งหมด

## หมวดที่ใช้บ่อย

`WAVE_SEND_RATE_EXCEEDED`, `WAVE_TEMPLATE_INVALID`, `WAVE_DELIVERABILITY_PAUSED` — ดูรายชื่อเต็มที่ [[convention/synthetic-marketing-automation/api-response-format]]
