# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(consent-manager): แก้ recurring campaign path ให้เช็ค consent ก่อนส่ง`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-marketing-automation/branch-naming]]
