# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(purchase-order-engine): เพิ่ม idempotency check สำหรับ create PO endpoint`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-supply-chain/branch-naming]]
