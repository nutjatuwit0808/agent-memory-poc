# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(warehouse-loader): กัน duplicate row ตอน retry`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-analytics-pipeline/branch-naming]]
