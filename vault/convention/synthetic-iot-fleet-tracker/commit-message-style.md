# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(geofence-engine): กัน cache ค้างตอนแก้ไขโซนเดิม`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-iot-fleet-tracker/branch-naming]]
