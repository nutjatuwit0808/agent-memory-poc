# Error Code Convention

## รูปแบบ

`ASSET_<DOMAIN>_<REASON>` เช่น `ASSET_LICENSE_OVERALLOCATED`, `ASSET_DISPOSAL_CERT_MISSING` ตัวพิมพ์ใหญ่ทั้งหมด

## หมวดที่ใช้บ่อย

`ASSET_REGISTRY_NOT_FOUND`, `ASSET_ASSIGNMENT_ALREADY_ASSIGNED`, `ASSET_PROCUREMENT_TIER_EXCEEDED` — ดูรายชื่อเต็มที่ [[convention/synthetic-asset-management/api-response-format]]
