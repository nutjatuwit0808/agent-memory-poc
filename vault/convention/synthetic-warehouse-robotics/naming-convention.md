# Naming Convention

## ตัวแปรและฟังก์ชัน

`camelCase` เช่น `attemptPick`, `computeGripProfile` — ฟังก์ชัน async ขึ้นต้นด้วยคำกริยาสื่อ action ไม่เติม `Async` ต่อท้าย

## Identifier ทางกายภาพ

`robotId` รูปแบบ `R-<4 หลัก>`, `binId` รูปแบบ `<zone>-<aisle>-<shelf>` เช่น `B-14-3` ต้องตรงกับ physical label บนคลังจริงเสมอ
