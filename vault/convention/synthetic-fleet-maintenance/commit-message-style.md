# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(parts-inventory): แก้ optimistic lock condition ป้องกัน negative stock`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — scope ควรตรงกับชื่อ module หรือ policy ที่แก้ไข
