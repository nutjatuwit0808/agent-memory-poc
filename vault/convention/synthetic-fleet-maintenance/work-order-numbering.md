# Work Order Numbering

## รูปแบบ

`WO-<YYYYMM>-<เลขลำดับ 5 หลัก>` เช่น `WO-202409-00142` เลขลำดับ reset ทุกเดือน

## กติกา

work order ที่ถูก reopen หลัง close จะได้ suffix `-R1`, `-R2` ตามจำนวนครั้งที่ reopen เพื่อให้ audit trail ชัดว่า close ครั้งแรกเมื่อไหร่
