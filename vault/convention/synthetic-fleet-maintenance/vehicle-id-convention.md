# Vehicle ID Convention

## รูปแบบ

`VH-<เลข 4 หลัก>` เช่น `VH-0412` ตัวเลขต้องตรงกับป้ายทะเบียนภายในของบริษัท รถสำรองใช้ suffix `B` เช่น `VH-0412B`

## กติกา

ห้ามใช้ทะเบียนรถจริง (ทะเบียนรัฐ) เป็น ID ในระบบเพราะทะเบียนเปลี่ยนได้เมื่อโอนรถ ใช้ internal ID เสมอ
