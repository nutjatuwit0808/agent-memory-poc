# SPC Chart Naming

## รูปแบบ

`<product-line-id>_<characteristic>_<chart-type>` เช่น `PL03_diameter_xbar`, `PL03_diameter_r` — chart type ใช้ lowercase เสมอ: `xbar`, `r`, `p`, `c`, `cusum`

## Characteristic code

ต้องตรงกับ Drawing Characteristic Number (DCN) ในแบบทางวิศวกรรม ไม่ใช่ชื่อเรียกภายในที่สั้นกว่า เพื่อให้ trace กลับไปถึงสเปกได้
