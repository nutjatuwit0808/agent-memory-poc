# Inspection Report Naming

## รูปแบบไฟล์

`RPT-<batch-id>-<inspector-id>-<YYYYMMDDHHMMSS>.pdf` เช่น `RPT-QP-20240901-014-INS042-20240901143022.pdf`

## การ link กลับ system

ทุก report ต้องมี QR code ที่ encode batch_id เพื่อให้ scan ด้วยมือถือแล้ว pull สถานะปัจจุบันจากระบบได้โดยตรง
