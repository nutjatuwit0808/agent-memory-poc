# Defect Code Taxonomy

## โครงสร้าง

`QP_<CATEGORY>_<REASON>` เช่น `QP_DIM_OVERSIZE`, `QP_SURF_SCRATCH`, `QP_WEIGHT_UNDERSPEC` — category ใช้ตัวย่อ 4 ตัว เพื่อให้อ่านออกโดยไม่ต้องเปิดเอกสาร

## Category ที่ใช้บ่อย

`DIM` (dimensional), `SURF` (surface), `WEIGHT` (weight), `COMP` (composition), `FUNC` (functional test) — เพิ่ม category ใหม่ต้องผ่าน QA Manager ก่อน
