# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(driver-dispatch): แก้ race condition ใน assignOrderToDriver`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-food-delivery/branch-naming]]
