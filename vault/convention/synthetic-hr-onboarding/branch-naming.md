# Branch Naming

## รูปแบบ

`<type>/<เลข-ticket>-<คำอธิบายสั้น>` ตัวอย่าง: `feat/ONB-142-day-one-access-deadline`, `fix/ONB-158-duplicate-task-dedup`

## กติกา

ต้องมีเลข ticket เสมอ ใช้ `kebab-case` ไม่เกิน 5 คำ branch ที่ merge แล้วลบทิ้งทันที ดู [[convention/synthetic-hr-onboarding/commit-message-style]] สำหรับ prefix ที่ใช้ร่วมกัน
