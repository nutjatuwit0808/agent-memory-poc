# Commit Message Style

## รูปแบบ

`<type>(<scope>): <คำอธิบาย>` เช่น `fix(document-collection): เพิ่ม handler สำหรับ webhook validation_failed`

## Type ที่ใช้

`feat`, `fix`, `refactor`, `docs`, `chore` — ตรงกับ prefix ของ [[convention/synthetic-hr-onboarding/branch-naming]]
