# Error Code Convention

## รูปแบบ

`ONB_<DOMAIN>_<REASON>` เช่น `ONB_PROVISION_QUEUE_FULL`, `ONB_DOC_STUCK` ตัวพิมพ์ใหญ่ทั้งหมด

## หมวดที่ใช้บ่อย

`ONB_BGCHECK_TIMEOUT`, `ONB_TASK_DUPLICATE`, `ONB_BUDDY_NO_CANDIDATE` — ดูรายชื่อเต็มที่ [[convention/synthetic-hr-onboarding/api-response-format]]
