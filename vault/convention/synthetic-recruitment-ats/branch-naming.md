# Branch Naming

## รูปแบบ

`<type>/<เลข-ticket>-<คำอธิบายสั้น>` ตัวอย่าง: `feat/ATS-203-offer-approval-reroute`, `fix/ATS-217-duplicate-candidate-merge`

## กติกา

ต้องมีเลข ticket เสมอ ใช้ `kebab-case` ไม่เกิน 5 คำ branch ที่ merge แล้วลบทิ้งทันที ดู [[convention/synthetic-recruitment-ats/commit-message-style]] สำหรับ prefix ที่ใช้ร่วมกัน
