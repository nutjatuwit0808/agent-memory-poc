# Case 1884 — CDN cache manifest เก่าทำผู้ชม live event เห็น segment ไม่ครบ

## สรุปเคส

ระหว่าง live event ผู้ชมบางกลุ่มเห็นวิดีโอค้างไม่เดินหน้าต่อ ทั้งที่ segment ใหม่ถูกสร้างและเผยแพร่ไปแล้วตามปกติ

## การตรวจสอบ

ตรวจ [[structure/synthetic-video-streaming/module-cdn-origin-shield]] พบว่า manifest ที่ผู้ชมกลุ่มนี้ได้รับเป็นเวอร์ชันเก่ากว่าที่ [[structure/synthetic-video-streaming/module-playlist-generator]] อัปเดตไปแล้วหลายรอบ

## สาเหตุ

response header ที่ควบคุม cache TTL ของ manifest ไม่ถูกตั้งให้สั้นพอสำหรับ live event ในบาง edge node เพราะ config cache TTL ถูก override โดยค่า default ของ CDN provider ที่ยาวกว่าที่ [[business-logic/synthetic-video-streaming/origin-shield-cache-policy]] กำหนดไว้

## การแก้ไข

purge cache manifest ทุก edge node ด้วยมือทันที แล้วยืนยัน config cache-control header ที่ CDN provider ให้ตรงกับค่าที่ตั้งใจไว้จริง

## Follow-up

เพิ่ม automated check เปรียบเทียบ cache TTL ที่ config ไว้กับค่าที่ CDN provider ใช้จริงเป็นระยะ เพื่อจับ config drift แบบนี้ก่อนกระทบผู้ชม
