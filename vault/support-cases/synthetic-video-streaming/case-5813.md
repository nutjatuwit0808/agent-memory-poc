# Case 5813 — เลือก codec ผิดทำอุปกรณ์รุ่นเก่าเล่นวิดีโอไม่ได้เป็นวงกว้าง

## สรุปเคส

หลังเปลี่ยนมาตรฐาน default codec เป็น HEVC เพื่อประหยัด bandwidth ทีม support ได้รับรายงานว่าผู้ชมที่ใช้อุปกรณ์รุ่นเก่าเล่นวิดีโอใหม่ไม่ได้เลยจำนวนมาก

## การตรวจสอบ

ตรวจ [[structure/synthetic-video-streaming/module-bitrate-ladder-selector]] พบว่า `selectRenditionsForDevice` ไม่มี rung สำรอง H.264 เหลือให้เลือกเลยสำหรับ ladder ที่สร้างหลัง deploy ครั้งนี้

## สาเหตุ

การเปลี่ยน default codec ลืมคง rung สำรอง H.264 ไว้อย่างน้อย 1 rung ตามที่ [[business-logic/synthetic-video-streaming/bitrate-ladder-selection-policy]] กำหนดไว้ เพราะโค้ดที่แก้ไปแตะเฉพาะ default codec ของ rung หลักโดยไม่ได้ตรวจสอบ edge case นี้

## การแก้ไข

deploy hotfix คืน rung สำรอง H.264 กลับเข้า ladder แล้ว trigger transcode ใหม่ให้ asset ที่สร้างระหว่างช่วงที่ได้รับผลกระทบทั้งหมด

## Follow-up

เพิ่ม automated test ที่ตรวจว่าทุก ladder ที่สร้างต้องมี rung H.264 อย่างน้อย 1 rung เสมอ ก่อนอนุญาตให้ deploy เปลี่ยน default codec ครั้งต่อไป
