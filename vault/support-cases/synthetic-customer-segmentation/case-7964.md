# Case 7964 — Health Monitor แจ้ง Critical Alert ทุกวันสำหรับ Segment ที่ว่างตั้งใจ

## สรุปเคส

ทีม marketing ได้รับ critical alert จาก [[structure/synthetic-customer-segmentation/module-health-monitor]] ทุกวันสำหรับ segment ที่สร้างขึ้นเพื่อ AB test โดยออกแบบให้ membership เป็น 0 จนกว่าจะ activate

## การตรวจสอบ

ตรวจ health score calculation พบว่า segment ที่มี membership 0 ได้คะแนน 0 โดยอัตโนมัติและถูก mark เป็น `critical` — ตรงตาม [[business-logic/synthetic-customer-segmentation/health-score-threshold-policy]] แต่ไม่ใช่สิ่งที่ทีมต้องการในกรณีนี้

## สาเหตุ

ไม่มีวิธีบอกระบบว่า segment นั้น intentionally empty ทำให้ทุก segment ที่ membership เป็น 0 ถูก treat เหมือนกัน ไม่ว่าจะเป็น error หรือ by design

## การแก้ไข

เพิ่ม `allow_empty=true` flag ใน segment definition ของ AB test segment เพื่อ suppress membership-based scoring ตาม [[business-logic/synthetic-customer-segmentation/health-score-threshold-policy]] alert หยุดทันที

## Follow-up

เพิ่ม `allow_empty` ใน segment creation form สำหรับ test segment type และ document ว่าควรใช้เมื่อไหร่ใน onboarding ของทีม marketing
