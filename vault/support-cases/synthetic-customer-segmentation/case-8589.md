# Case 8589 — Event Ingester Reject Event จำนวนมากหลัง Source System Update Schema

## สรุปเคส

ระบบ e-commerce อัปเดต schema ของ purchase event โดยเพิ่ม required field ใหม่ ทำให้ [[structure/synthetic-customer-segmentation/module-event-ingester]] reject purchase event ทุกชิ้นด้วย `schema_invalid` เป็นเวลาหลายชั่วโมง

## การตรวจสอบ

ตรวจ reject log พบว่า event ingester ใช้ schema version เก่าที่ไม่รู้จัก field ใหม่ `purchase_channel` และตีความว่า event ที่มี field นี้ผิด schema

## สาเหตุ

ไม่มีกระบวนการ coordinate schema change ระหว่าง e-commerce team และ SegmentIQ team ก่อน deploy — e-commerce deploy schema ใหม่โดยไม่แจ้ง SegmentIQ ให้ update schema validator ก่อน

## การแก้ไข

อัปเดต schema version ใน [[structure/synthetic-customer-segmentation/module-event-ingester]] ให้รองรับ field ใหม่ และ re-ingest event ที่ถูก reject ทั้งหมดจาก dead-letter queue

## Follow-up

สร้าง schema change notification process ให้ source system แจ้ง SegmentIQ ล่วงหน้าอย่างน้อย 1 sprint ก่อน deploy schema ใหม่
