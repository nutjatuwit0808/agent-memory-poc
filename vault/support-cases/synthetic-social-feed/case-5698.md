# Case 5698 — ผู้ใช้ได้รับแจ้งเตือนโพสต์เดียวกันซ้ำหลายครั้ง

## สรุปเคส

ผู้ใช้จำนวนหนึ่งร้องเรียนว่าได้รับแจ้งเตือนโพสต์เดียวกันจากคนเดียวกันซ้ำ 4-5 ครั้งในเวลาไม่กี่นาที

## การตรวจสอบ

ตรวจ `dedupNotification` ใน [[structure/synthetic-social-feed/module-notification-fanout]] พบว่า dedup key ชนกันเมื่อ fanout job เดิมถูกแบ่งเป็นหลาย batch ที่รันพร้อมกันบน worker คนละตัว

## สาเหตุ

dedup check อ่านและเขียนสถานะแบบไม่ atomic ระหว่าง worker คนละตัว ทำให้สอง batch ที่มี follower คนเดียวกันซ้ำกันโดยบังเอิญต่างก็ผ่านการเช็ค dedup ไปพร้อมกัน

## การแก้ไข

แก้ dedup check ให้ใช้ atomic operation ระดับ database แทนการอ่านแล้วเขียนแยกกัน deploy เป็น hotfix

## Follow-up

ตรวจสอบ batch อื่นใน [[structure/synthetic-social-feed/module-notification-fanout]] ที่มี pattern คล้ายกันว่ามีความเสี่ยง race condition เดียวกันหรือไม่
