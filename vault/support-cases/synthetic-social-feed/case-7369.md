# Case 7369 — Feed-ranker Timeout ทำแอปโหลดไม่ขึ้นทั้งระบบ

## สรุปเคส

ผู้ใช้จำนวนมากรายงานว่าเปิดแอปแล้วหน้า feed โหลดไม่ขึ้นเลยนานเกือบ 20 นาทีช่วงเย็นวันหนึ่ง

## การตรวจสอบ

ตรวจ [[structure/synthetic-social-feed/module-feed-ranker]] พบว่า database connection pool เต็มเนื่องจากมี query ช้าผิดปกติค้างอยู่จำนวนมาก ทำให้ request ใหม่ต้องรอ connection จนเกิน timeout ของ API gateway

## สาเหตุ

query ที่ช้าเกิดจาก index ที่หายไปหลัง migration schema เมื่อคืนก่อนหน้า ทำให้ query ที่เคยเร็วกลายเป็น full table scan โดยไม่มีใครสังเกตในการทดสอบก่อน deploy

## การแก้ไข

เพิ่ม index ที่หายไปกลับเข้าไปแบบ `CREATE INDEX CONCURRENTLY` ไม่ล็อกตาราง แก้ปัญหาได้ภายใน 10 นาทีหลัง index สร้างเสร็จ

## Follow-up

เพิ่มการตรวจสอบ query plan อัตโนมัติใน [[deployment/synthetic-social-feed/ci-cd-pipeline]] ก่อน migration schema ทุกครั้งที่แตะตารางหลัก
