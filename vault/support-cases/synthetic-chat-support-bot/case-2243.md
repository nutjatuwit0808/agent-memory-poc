# Case 2243 — คิว Handoff ล้นช่วงพีคทำลูกค้ารอนานผิดปกติ

## สรุปเคส

ระหว่าง peak support window ช่วงเช้า ทีมเจ้าหน้าที่รายงานว่าคิวรอ handoff ยาวขึ้นเรื่อยๆ ลูกค้าบางรายรอเกิน 20 นาทีทั้งที่ปกติไม่เกิน 5 นาที

## การตรวจสอบ

ตรวจ [[structure/synthetic-chat-support-bot/module-handoff-router]] พบว่าความลึกคิวเกิน `HANDOFF_MAX_QUEUE_DEPTH` ไปมากตั้งแต่ช่วงต้นชั่วโมง แต่ alert ที่ควรแจ้งหัวหน้าทีมไม่ถูกส่งออก

## สาเหตุ

จำนวนเจ้าหน้าที่ที่ล็อกอินเข้าระบบวันนั้นน้อยกว่าปกติเพราะเป็นวันที่มีการประชุมทีมพร้อมกันตอนเช้า ไม่มีใครปรับตารางกะให้เหลื่อมเวลาป้องกันช่วง peak window เหมือนที่ควรทำ

## การแก้ไข

หัวหน้าทีมเรียกเจ้าหน้าที่กลับเข้าระบบด่วนบางส่วน พร้อมเปิด edge case ของ [[business-logic/synthetic-chat-support-bot/handoff-escalation-policy]] ให้จัดคิวใหม่บ่อยขึ้นชั่วคราวเพื่อลดการรอซ้ำ

## Follow-up

เพิ่มกฎห้ามจัดประชุมทีมเจ้าหน้าที่ทั้งหมดพร้อมกันในช่วง peak support window และตรวจสอบว่าทำไม alert ไม่ถูกส่งออกตามที่ควร
