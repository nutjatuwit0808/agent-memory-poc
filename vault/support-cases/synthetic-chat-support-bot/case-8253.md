# Case 8253 — State บทสนทนาหายกลางคันหลัง deploy

## สรุปเคส

หลัง deploy เวอร์ชันใหม่ของ [[structure/synthetic-chat-support-bot/module-conversation-state-manager]] ลูกค้าหลายรายรายงานว่า bot ถามคำถามที่เพิ่งตอบไปแล้วซ้ำ เหมือนบทสนทนาเริ่มใหม่กลางคัน

## การตรวจสอบ

ตรวจ log พบว่า `getConversationContext` คืนอาร์เรย์ว่างเปล่าสำหรับบทสนทนาที่มี turn มากกว่า `MAX_CONTEXT_TURNS_FOR_HANDOFF` อยู่แล้วก่อน deploy

## สาเหตุ

การ refactor query ดึงประวัติ turn ในเวอร์ชันใหม่เปลี่ยนเงื่อนไข pagination โดยไม่ตั้งใจ ทำให้บทสนทนาที่มี turn เกินขนาด page แรกไม่ถูกดึงกลับมาเลยแทนที่จะดึงมาบางส่วน

## การแก้ไข

rollback deploy กลับเวอร์ชันก่อนหน้าตาม [[deployment/synthetic-chat-support-bot/rollback-procedure]] ทันที แล้ว fix pagination logic ให้ถูกต้องก่อน deploy ใหม่อีกครั้งพร้อม test เพิ่ม

## Follow-up

เพิ่ม integration test ที่จำลองบทสนทนายาวเกิน 1 page เข้า [[convention/synthetic-chat-support-bot/testing-convention]] เพื่อจับ regression แบบนี้ก่อนขึ้นจริง
