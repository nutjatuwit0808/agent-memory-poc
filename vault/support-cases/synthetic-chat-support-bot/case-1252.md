# Case 1252 — ลืมคืนค่า Rate Limit หลังทดสอบทำ Traffic ปกติถูกบล็อก

## สรุปเคส

วันหนึ่งทีม support ได้รับรายงานจากหลายองค์กรลูกค้าพร้อมกันว่าข้อความถูกปฏิเสธบ่อยผิดปกติ ทั้งที่ปริมาณ traffic ไม่ได้สูงกว่าปกติมากนัก

## การตรวจสอบ

ตรวจ config ของ [[structure/synthetic-chat-support-bot/module-rate-limiter]] พบว่าค่า `RATE_LIMIT_BUCKET_CAPACITY` ถูกปรับลดลงระหว่างการทดสอบพฤติกรรมภายใต้ load ต่ำเมื่อสัปดาห์ก่อน แต่ไม่ได้ปรับกลับหลังทดสอบเสร็จ

## สาเหตุ

ขั้นตอนทดสอบไม่มี checklist บังคับให้ยืนยันคืนค่า config กลับหลังทดสอบเสร็จ ทำให้ค่าที่ตั้งไว้ชั่วคราวสำหรับทดสอบหลุดเข้าสู่ production โดยไม่มีใครสังเกต

## การแก้ไข

ปรับค่า `RATE_LIMIT_BUCKET_CAPACITY` กลับเป็นค่าที่ตั้งใจไว้เดิมทันที แล้วรีเซ็ต bucket ของ account ที่ถูกบล็อกผิดพลาดทั้งหมดด้วย `resetBucket`

## Follow-up

เพิ่มขั้นตอนยืนยันคืนค่า config หลังการทดสอบทุกครั้งเป็นส่วนหนึ่งของ [[convention/synthetic-chat-support-bot/code-review-checklist]] สำหรับการเปลี่ยน config ที่กระทบ rate limit
