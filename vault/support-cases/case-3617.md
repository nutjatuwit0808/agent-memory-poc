# Case 3617 — ลูกค้าแจ้งธนาคารขอเงินคืนโดยตรง

## สรุปเคส

order #ORD-91203 ถูก mark เป็น `disputed` อัตโนมัติ ทีม support ต้องรวบรวมหลักฐานส่งกลับให้ payment gateway ภายในกำหนดเวลา

## การตรวจสอบ

ตรวจสอบ log พบว่าลูกค้าได้รับสินค้าแล้วจริง (มี tracking ยืนยันการส่งถึง) และไม่เคยติดต่อ support ผ่านช่องทางปกติมาก่อนเลย ตรงกับ pattern ที่อธิบายไว้ใน [[business-logic/dispute-resolution-process]] ที่ลูกค้าบางส่วนเลือกติดต่อธนาคารโดยตรงแทนที่จะขอคืนเงินผ่านระบบ

## การแก้ไข

รวบรวมหลักฐานการจัดส่งและ log การสื่อสารทั้งหมดส่งให้ payment gateway ภายในกำหนด 7 วันตามกระบวนการ

## Follow-up

รอผลตัดสินจากธนาคาร คาดว่าใช้เวลาอีกหลายสัปดาห์ — เคสนี้ยังไม่ปิด อยู่ระหว่างติดตามผล
