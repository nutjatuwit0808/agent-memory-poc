# Case 3728 — สั่งซื้อสำเร็จแต่แจ้งว่าของหมด

## สรุปเคส

ลูกค้าสั่งซื้อสินค้าลดราคาชิ้นสุดท้ายสำเร็จ ได้รับอีเมลยืนยัน order แต่หลังจากนั้นไม่กี่นาทีได้รับแจ้งว่าสินค้าหมดสต็อกและ order ถูกยกเลิก ลูกค้างุนงงว่าทำไมยืนยันสำเร็จแล้วถึงยกเลิกได้

## การตรวจสอบ

ตรวจสอบ log พบว่ามีลูกค้าสองคนพยายาม `reserveStock` สินค้าชิ้นสุดท้ายในเวลาไล่เลี่ยกันมาก ตาม [[business-logic/inventory-reservation-rules]] ระบบใช้ optimistic locking ที่อนุญาตให้สำเร็จได้เพียงคำขอเดียว — ลูกค้าที่ถามมาเป็นคนที่ reserve สำเร็จจริง แต่กลับพบว่าอีกฝั่งกด "ยืนยันคำสั่งซื้อ" (checkout เสร็จสมบูรณ์) เร็วกว่าเล็กน้อยในระบบเก่าที่ยังมีช่องโหว่ทับซ้อนกันได้ในบางกรณีขอบ

## การแก้ไข

ขอโทษลูกค้าและเสนอส่วนลดพิเศษสำหรับการสั่งซื้อครั้งถัดไปเป็นการชดเชย ทีม engineering รับเรื่องไปตรวจสอบช่องโหว่ของ locking เพิ่มเติม

## Follow-up

ทีม engineering ยืนยันว่าเป็น edge case ที่หายากมากและได้แก้ไขจุดที่ locking ยังไม่ครอบคลุมกรณีขอบนี้แล้ว
