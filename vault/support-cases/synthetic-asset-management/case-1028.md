# Case 1028 — สินทรัพย์ถูก Dispose โดยไม่มีใบรับรอง Data Destruction

## สรุปเคส

พบระหว่าง compliance audit ว่า laptop 5 เครื่องถูก mark เป็น `disposed` ใน [[structure/synthetic-asset-management/module-asset-registry]] แต่ไม่มี data destruction certificate ใน [[structure/synthetic-asset-management/module-disposal-workflow]] สักฉบับ

## การตรวจสอบ

ตรวจ disposal record พบว่ามีคนใช้ admin endpoint ที่ bypass การตรวจสอบ certificate เพื่อ force complete disposal ของ laptop กลุ่มนี้โดยอ้างว่าเป็น emergency disposal จากเหตุฉุกเฉินทางกายภาพ

## สาเหตุ

admin endpoint นี้สร้างไว้สำหรับกรณีฉุกเฉินจริง แต่ไม่มีการ require justification หรือ second approval ทำให้ถูกใช้โดยไม่เหมาะสมตาม [[business-logic/synthetic-asset-management/disposal-certification-policy]]

## การแก้ไข

บันทึกเหตุการณ์ไว้ใน compliance incident log และตามหาใบรับรองย้อนหลังจากผู้ให้บริการ destroy ข้อมูล ได้ 4 จาก 5 เครื่อง เครื่องที่เหลือต้องทำ forensic investigation

## Follow-up

เพิ่ม mandatory justification และ second approval สำหรับ admin disposal endpoint พร้อมแจ้งเตือนอัตโนมัติไปยัง security team ทุกครั้งที่ endpoint นี้ถูกใช้
