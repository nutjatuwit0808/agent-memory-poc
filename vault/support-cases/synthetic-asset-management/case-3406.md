# Case 3406 — Procurement Request ได้รับ Approve เกินวงเงิน Tier จากช่องโหว่ Rounding

## สรุปเคส

request มูลค่า 500,001 บาท ผ่าน approval โดย manager (Tier 1) ได้ทั้งที่เกินวงเงิน `PROCUREMENT_TIER1_LIMIT_THB` ทำให้ director ไม่ได้รับโอกาส review

## การตรวจสอบ

ตรวจ code ใน [[structure/synthetic-asset-management/module-procurement-handler]] พบว่าการเปรียบเทียบ tier ใช้ `<=` กับค่าที่ตัดทศนิยมทิ้งก่อน ทำให้ 500,001 ถูกตัดเป็น 500,000 และผ่าน Tier 1 ได้

## สาเหตุ

bug ในการ format ตัวเลขสำหรับ comparison — ค่าที่ส่งมาจากระบบ ERP มีทศนิยม แต่ logic การเทียบ tier ใช้ค่า truncated แทนที่จะ round หรือใช้ค่าจริง

## การแก้ไข

แก้ให้ใช้ตัวเลขจริงโดยไม่ตัดทศนิยมก่อนเปรียบเทียบ tier ยกเลิก approval ที่ผิดพลาดและ escalate request ดังกล่าวให้ director review ตามขั้นตอนปกติ

## Follow-up

เพิ่ม test case สำหรับค่าที่อยู่บน boundary ของทุก tier โดยเฉพาะ และ review logic การเปรียบเทียบ tier ทั้งหมดใน [[structure/synthetic-asset-management/module-procurement-handler]] ครั้งเดียวกัน
