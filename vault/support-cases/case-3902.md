# Case 3902 — สมาชิกรายเดือนถูกยกเลิกอัตโนมัติ

## สรุปเคส

ลูกค้าสมาชิกรายเดือนพบว่าสิทธิ์ถูกยกเลิกไปเฉยๆ ทั้งที่ไม่ได้ตั้งใจยกเลิกเอง

## การตรวจสอบ

บัตรเครดิตที่ผูกไว้หมดอายุ ทำให้การเรียกเก็บเงินรอบล่าสุดล้มเหลว ระบบ retry ตามนโยบายเดียวกับ [[business-logic/payment-retry-policy]] ครบ 3 ครั้งแล้วยังไม่สำเร็จ เข้าสถานะ `past_due` ตาม [[business-logic/subscription-billing-cycle]] และมี grace period 3 วัน ซึ่งลูกค้าไม่ได้เข้ามาอัปเดตบัตรภายในเวลานั้น จึงถูกยกเลิกอัตโนมัติ

## การแก้ไข

ช่วยลูกค้าอัปเดตบัตรใหม่และเปิดสิทธิ์สมาชิกให้กลับมาใช้งานได้ทันทีเป็นกรณีพิเศษ เนื่องจากลูกค้ายืนยันว่าไม่เคยได้รับอีเมลแจ้งเตือนช่วง grace period

## Follow-up

ทีมตรวจสอบพบว่าอีเมลแจ้งเตือน `past_due` ถูกจัดเป็น spam โดย mail provider ของลูกค้าบางราย ส่งเรื่องให้ทีม notification ปรับปรุงเนื้อหาอีเมลเพื่อลดโอกาสโดน spam filter
