# Case 8986 — Payout engine คำนวณ surge bonus ผิดเพราะ timezone mismatch

## สรุปเคส

คนขับที่ทำงานช่วง 23:00-01:00 ได้รับ surge bonus ผิดพลาดเพราะ snapshot time ที่ใช้คำนวณอยู่ใน timezone UTC ที่ต่างวันจากเวลาจริงในประเทศ

## การตรวจสอบ

ตรวจ payout calculation ใน [[structure/synthetic-food-delivery/module-driver-payout-engine]] พบว่า `surge_multiplier` ถูก snapshot ด้วย timestamp UTC แต่ logic เลือก multiplier tier ใช้ local time ทำให้ช่วง 23:00-01:00 local ตก bucket ผิด

## สาเหตุ

ส่วนหนึ่งของ codebase ใช้ UTC อีกส่วนใช้ local timezone ไม่มี convention กลางที่ enforce ว่า timezone ไหนเป็น canonical

## การแก้ไข

แก้ทุก timestamp ใน payout_records ให้ store เป็น UTC เสมอ แล้ว convert เป็น local timezone เฉพาะตอนแสดงผลใน driver app เท่านั้น

## Follow-up

เขียน timezone convention ลงใน [[convention/synthetic-food-delivery/naming-convention]] และ add linting rule ที่ flag การใช้ `new Date()` โดยไม่ explicit timezone
