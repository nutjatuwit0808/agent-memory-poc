# Case 5359 — Surge multiplier ค้างไม่อัปเดตระหว่าง lunch peak

## สรุปเคส

ช่วง lunch peak surge multiplier ของหลายโซนค้างที่ค่าเดิมนาน 45 นาที ทั้งที่ demand/supply ratio เปลี่ยนไปมากแล้ว

## การตรวจสอบ

ตรวจ [[structure/synthetic-food-delivery/module-surge-pricer]] พบว่า background job ที่คำนวณ multiplier ใหม่ทุก 30 วินาทีหยุดทำงานกะทันหัน โดยไม่มี alert ใดๆ เพราะ job crash แบบ silent ไม่ throw exception ออกมา

## สาเหตุ

Job ใช้ข้อมูล `pendingOrders` จาก [[structure/synthetic-food-delivery/module-order-router]] ผ่าน internal API call ที่ไม่มี timeout กำหนด เมื่อ order-router response ช้าช่วง peak job จึงค้างรอโดยไม่มีกำหนด และ goroutine pool ของ surge-pricer เต็ม

## การแก้ไข

เพิ่ม timeout 5 วินาทีในการ call order-router และเพิ่ม monitoring ที่ alert ถ้า multiplier refresh หยุดทำงานนานเกิน 60 วินาที restart service ด้วยมือเพื่อ clear goroutine leak

## Follow-up

ตรวจสอบ internal API call ทุกจุดใน surge-pricer ที่ยังไม่มี timeout กำหนด และพิจารณา circuit breaker pattern เพื่อหลีกเลี่ยง cascade slow ครั้งต่อไป
