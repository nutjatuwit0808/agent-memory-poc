# Case 3105 — โค้ดส่วนลดใช้ไม่ได้ตอน checkout

## สรุปเคส

ลูกค้าใส่โค้ด `SUMMER20` แล้วระบบแจ้ง error ว่าโค้ดหมดอายุ ทั้งที่เว็บโฆษณาว่าโค้ดใช้ได้ถึงสิ้นเดือน

## การตรวจสอบ

ลูกค้าเปิดหน้า checkout ค้างไว้นานเกือบ 40 นาทีก่อนกดยืนยัน — ตาม [[business-logic/promo-code-rules]] วันหมดอายุคำนวณจาก timestamp ที่ order ถูกสร้าง ซึ่งกรณีนี้ order ถูกสร้างหลังโค้ดหมดอายุไปแล้วพอดี แม้ตอนที่ลูกค้าเริ่ม checkout โค้ดจะยังไม่หมดอายุก็ตาม

## การแก้ไข

อธิบายกลไกให้ลูกค้าทราบ และให้โค้ดทดแทนมูลค่าเท่ากันเป็นกรณีพิเศษเนื่องจากช่วงเวลาที่หมดอายุใกล้เคียงกับตอนที่ลูกค้าเริ่ม checkout มาก

## Follow-up

เสนอในทีมว่าควรแสดง countdown ชัดเจนบนหน้า checkout เมื่อโค้ดใกล้หมดอายุ เพื่อลดเคสแบบนี้ในอนาคต — ยังไม่ได้ตัดสินใจว่าจะทำ
