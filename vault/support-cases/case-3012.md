# Case 3012 — ลูกค้าอยากยกเลิกรายการแต่กดในแอปไม่ได้

## สรุปเคส

ลูกค้าต้องการยกเลิกรายการ order #ORD-89012 แต่ปุ่มยกเลิกในแอปหายไป ลูกค้าสงสัยว่าเป็นบั๊ก

## การตรวจสอบ

เช็คสถานะ order พบว่าเป็น `packed` แล้ว — ตามนโยบายใน [[business-logic/order-cancellation-policy]] เมื่อเข้าสถานะนี้ ลูกค้าจะยกเลิกเองผ่านแอปไม่ได้อีกต่อไป ปุ่มหายไปเพราะ frontend ซ่อนตามสถานะนี้ตามที่ตั้งใจออกแบบไว้ ไม่ใช่บั๊ก

## การแก้ไข

อธิบายให้ลูกค้าทราบว่าสินค้าถูกแพ็คแล้ว และถ้ายังต้องการยกเลิกจะดำเนินการเป็นคำขอคืนเงินแทนหลังได้รับสินค้า ลูกค้าเข้าใจและรอรับสินค้าตามปกติ

## Follow-up

ไม่มีการดำเนินการเพิ่มเติม ปิดเคสเป็น "อธิบายตามนโยบายปกติ" ไม่ใช่บั๊ก
