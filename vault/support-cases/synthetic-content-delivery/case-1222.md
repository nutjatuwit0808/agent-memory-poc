# Case 1222 — Edge Node ใน Region หนึ่งออฟไลน์กระทบ Traffic ทั้ง Region

## สรุปเคส

ผู้ใช้ใน Asia-Pacific region ได้รับ 502 Bad Gateway นานกว่า 15 นาที ทั้งที่ service ของ EdgeServe ยังทำงานปกติใน region อื่น

## การตรวจสอบ

ตรวจ health check ของ edge node ใน AP region พบว่า 3 ใน 5 PoP ใน region ออฟไลน์พร้อมกัน [[structure/synthetic-content-delivery/module-geo-router]] ตรวจจับได้ แต่ failover ไปยัง region อื่นช้ากว่าที่ควรเพราะ health check threshold ตั้งไว้ 3 consecutive failure ซึ่งใช้เวลา 30 วินาที

## สาเหตุ

Network maintenance ของ upstream provider ใน region ทำให้ PoP หลายจุดออฟไลน์พร้อมกันชั่วคราว — ระบบ failover ทำงานถูกต้องแต่ threshold ออกแบบมาสำหรับ single node failure ไม่ใช่ mass failure ในระดับ region

## การแก้ไข

ลด health check failure threshold จาก 3 เป็น 2 เพื่อให้ failover เร็วขึ้นในสถานการณ์ mass failure และเพิ่ม circuit breaker ระดับ region เพิ่มเติม

## Follow-up

เพิ่ม runbook สำหรับ manual regional failover ใน [[deployment/synthetic-content-delivery/incident-response-runbook]] และตรวจสอบ SLA กับ upstream provider เรื่อง maintenance notification
