# Case 9774 — LMS ภายนอกตอบช้าทำสถานะ Training ไม่อัปเดต

## สรุปเคส

พนักงานหลายคนอบรมความปลอดภัยข้อมูลเสร็จแล้วจริงในระบบ LMS แต่ [[structure/synthetic-hr-onboarding/module-compliance-tracker]] ยังแสดงว่ายังไม่เสร็จ ทำให้ถูก escalate ไปหาหัวหน้างานเป็น false positive

## การตรวจสอบ

ตรวจสอบ integration log พบว่า LMS ตอบ webhook ยืนยันการอบรมเสร็จช้ากว่าปกติมาก (บางครั้งเกิน 6 ชั่วโมง) ในช่วงที่ LMS ทำ maintenance โดยไม่แจ้งล่วงหน้า

## สาเหตุ

ไม่มี timeout handling พิเศษสำหรับกรณี LMS ตอบช้าผิดปกติ — ระบบ escalate ตาม deadline ปกติโดยไม่รู้ว่าจริงๆ แล้วอบรมเสร็จไปแล้ว แค่ webhook ยังไม่มาถึง

## การแก้ไข

query สถานะจาก LMS API โดยตรงสำหรับ item ที่ถูก escalate ทั้งหมดในช่วงนั้น พบว่าส่วนใหญ่เสร็จจริงแล้ว จึง mark completed ด้วยมือและแจ้งหัวหน้างานยกเลิก escalation ที่ผิดพลาด

## Follow-up

เพิ่มการ poll สถานะจาก LMS API เป็น fallback เมื่อไม่ได้รับ webhook ภายในเวลาที่คาด แทนการพึ่ง webhook อย่างเดียว คล้ายกับแนวทางที่ใช้ใน [[business-logic/synthetic-hr-onboarding/document-signature-policy]]
