# Case 7747 — Contractor ถูกจัดเป็นพนักงานประจำผิดประเภททำให้ onboarding ผิดเงื่อนไข

## สรุปเคส

พนักงาน contract คนหนึ่งถูกส่ง task และ compliance item ชุดเต็มของพนักงานประจำทั้งหมด รวมถึงถูกจับคู่ buddy ทั้งที่ตาม [[business-logic/synthetic-hr-onboarding/contractor-onboarding-variance-policy]] ไม่ควรเกิดขึ้น

## การตรวจสอบ

ตรวจสอบ `roleId` ที่ใช้สร้าง case พบว่าถูกตั้งเป็น role พนักงานประจำผิดพลาดตั้งแต่ตอนกรอกข้อมูลใน HRIS แล้ว [[structure/synthetic-hr-onboarding/module-onboarding-workflow-engine]] ก็ดึงค่าตามนั้นมาใช้ตรงๆ ไม่มีการ cross-check ประเภทการจ้างงาน

## สาเหตุ

ไม่มี validation ระหว่าง `employmentType` กับ `roleId` ที่เลือก — ระบบเชื่อค่าที่กรอกมาจาก HRIS ทั้งหมดโดยไม่ตรวจสอบความสอดคล้อง

## การแก้ไข

แก้ `roleId` ให้ถูกต้องด้วยมือ แล้วยกเลิก task/compliance item ที่ไม่เกี่ยวข้อง และยกเลิกการจับคู่ buddy ที่เกิดไปแล้วตามนโยบาย contractor

## Follow-up

เพิ่ม validation เตือนเมื่อ `employmentType` กับ role ที่เลือกไม่สอดคล้องกันตั้งแต่ตอนสร้าง case ก่อนที่จะ generate task ผิดชุดออกไป
