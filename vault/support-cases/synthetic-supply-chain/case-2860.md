# Case 2860 — Shipment tracking ค้างนาน 5 วันโดยไม่มี update ใดๆ

## สรุปเคส

Shipment SHP-2405-118 ที่มาจากซัพพลายเออร์ S-023 ไม่มี milestone update เลยนาน 5 วันหลังออกจากต้นทาง ทีม procurement ไม่รู้สินค้าอยู่ที่ไหนและจะถึงเมื่อไหร่

## การตรวจสอบ

ตรวจสอบ [[structure/synthetic-supply-chain/module-shipment-tracker]] พบว่าซัพพลายเออร์ส่ง ASN แล้วแต่ carrier ไม่ได้ส่ง tracking update กลับมา ตรวจสอบกับ carrier โดยตรงพบว่าระบบ webhook ของ carrier มีปัญหาและไม่ได้ส่ง event ไปยัง SupplyLink เลย

## สาเหตุ

Carrier ทำการ system maintenance โดยไม่แจ้งล่วงหน้าและ webhook ของพวกเขาหยุดทำงานชั่วคราว SupplyLink ไม่มีระบบตรวจสอบว่า webhook ของ carrier ยังทำงานปกติหรือไม่นอกจากรอรับ event

## การแก้ไข

ติดต่อ carrier โดยตรงเพื่อรับ status update สินค้าอยู่ระหว่างขนส่งปกติ update timeline ใน shipment tracker ด้วยมือ และ escalate carrier ให้แก้ webhook ก่อนปิด incident

## Follow-up

เพิ่ม periodic heartbeat check ที่ polling carrier API โดยตรงเป็น fallback เมื่อไม่มี webhook update เกิน threshold ดู [[business-logic/synthetic-supply-chain/shipment-tracking-staleness-policy]]
