# Case 6844 — Batch ค้าง quarantine หลัง rework ผ่านแล้ว 2 วัน

## สรุปเคส

ฝ่ายขายแจ้งว่า shipment ที่ควรส่งได้ถูก block โดย [[structure/synthetic-quality-control/module-quarantine-manager]] ทั้งที่ QC team ยืนยันว่า rework ผ่านไปตั้งแต่ 2 วันก่อนแล้ว

## การตรวจสอบ

ตรวจ log [[structure/synthetic-quality-control/module-batch-inspector]] ยืนยันว่า batch ผ่าน rework inspection จริงเมื่อ 48 ชั่วโมงที่แล้ว แต่ [[structure/synthetic-quality-control/module-quarantine-manager]] ยังมี active hold อยู่เพราะยังไม่มีใคร call `releaseHold` ด้วยมือ

## สาเหตุ

ระบบ escalation alert ที่ควร notify เมื่อ rework ผ่านแล้วแต่ hold ยังไม่ release ไม่ทำงานเพราะ `QUARANTINE_EXPIRY_LOOKAHEAD_HOURS` ที่ตั้งไว้ไม่ครอบคลุม scenario นี้ (alert ส่งตาม hold expiry เท่านั้น ไม่ส่งตาม rework completion)

## การแก้ไข

QC Manager release hold ด้วยมือทันที หลังยืนยัน evidence จาก batch inspector log Shipment ออกไปได้ภายใน 2 ชั่วโมงหลังพบปัญหา

## Follow-up

เพิ่ม alert แยกสำหรับ hold ที่ batch ผ่าน rework แล้วแต่ยังไม่ release เกิน 24 ชั่วโมง ตาม [[business-logic/synthetic-quality-control/quarantine-hold-duration-policy]]
