# Case 2933 — Process parameter ของ SPC ไม่ได้อัปเดตหลัง process change

## สรุปเคส

หลังทีม engineering ปรับ process ของสาย PL-06 เพื่อลด cycle time control limit ของ SPC ยังใช้ parameter เก่า ทำให้ alarm rate เพิ่มขึ้น 300% โดยไม่มีของจริงเสียหายเลย

## การตรวจสอบ

เปรียบเทียบ SPC parameter ใน [[structure/synthetic-quality-control/module-spc-analyzer]] กับ process spec ฉบับใหม่ พบว่า engineering ส่ง change request ให้ QC แต่ QC team อัปเดต process spec เฉพาะในเอกสาร Word ไม่ได้ update ผ่าน `updateProcessParameters` ในระบบ

## สาเหตุ

ไม่มีขั้นตอน mandatory ที่บังคับให้ update SPC parameter ในระบบเป็นส่วนหนึ่งของ process change workflow ทำให้ขึ้นอยู่กับว่า QC จะจำทำหรือไม่

## การแก้ไข

อัปเดต SPC parameter ให้ตรงกับ process spec ใหม่ recalculate control limit และ dismiss false alarm ทั้งหมดในช่วง 2 สัปดาห์หลัง process change

## Follow-up

เพิ่ม step ที่บังคับ update SPC parameter ใน [[convention/synthetic-quality-control/inspection-report-naming]] checklist สำหรับ process change ทุกครั้ง
