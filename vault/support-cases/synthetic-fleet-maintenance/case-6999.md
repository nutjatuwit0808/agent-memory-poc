# Case 6999 — ช่างใช้อะไหล่จาก vendor ที่ไม่ได้ approved โดยไม่แจ้ง

## สรุปเคส

Parts audit พบว่า brake component รุ่นหนึ่งใน stock มาจาก vendor ที่ไม่อยู่ใน approved list และถูก install ใน work order 5 ใบแล้ว

## การตรวจสอบ

ตรวจ purchase record พบว่า Purchasing Manager ซื้อจาก vendor ที่ไม่ approved โดยอ้างว่าได้รับ verbal approval จาก Operations Director ระหว่าง emergency ซึ่งไม่ได้บันทึกใน [[structure/synthetic-fleet-maintenance/module-reorder-trigger]]

## สาเหตุ

emergency approval process ตาม [[business-logic/synthetic-fleet-maintenance/vendor-approval-non-stocked-parts-policy]] ต้องบันทึกใน system แต่ Purchasing Manager ใช้ verbal approval แทนเพราะรู้สึกว่าระบบช้าเกินไปในสถานการณ์ฉุกเฉิน

## การแก้ไข

ถอด brake component ที่ install แล้วทั้ง 5 คัน และ inspect ว่า component เหล่านั้นมีมาตรฐานเพียงพอหรือไม่ Fleet Safety Officer ประเมิน risk

## Follow-up

เพิ่ม fast-track approval path ใน [[structure/synthetic-fleet-maintenance/module-reorder-trigger]] สำหรับ emergency ที่ใช้เวลาไม่เกิน 5 นาที เพื่อลดแรงจูงใจที่จะ bypass ระบบ
