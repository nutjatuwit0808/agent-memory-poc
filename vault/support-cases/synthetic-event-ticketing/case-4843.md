# Case 4843 — รายการขายต่อไม่หมดอายุใกล้วันงานตามที่ควร

## สรุปเคส

ผู้ซื้อรายหนึ่งซื้อบัตรจากตลาดขายต่อเพียง 2 ชั่วโมงก่อนงานเริ่ม แต่กระบวนการโอนกรรมสิทธิ์ไม่เสร็จทันเวลา ทำให้เข้างานไม่ได้

## การตรวจสอบ

ตรวจ [[structure/synthetic-event-ticketing/module-resale-marketplace]] พบว่ากฎที่ควรหมดอายุรายการลงขายเร็วขึ้นเมื่อวันงานใกล้เข้ามาน้อยกว่า 24 ชั่วโมง (ตามที่ระบุใน [[business-logic/synthetic-event-ticketing/resale-listing-expiry-policy]]) ไม่เคย implement จริง มีแค่ TTL มาตรฐาน `RESALE_LISTING_EXPIRY_DAYS` เท่านั้น

## สาเหตุ

นโยบายระบุเงื่อนไขพิเศษไว้แต่การพัฒนาไม่ได้ implement ตามที่ระบุครบทุกกรณี เป็นช่องว่างระหว่างเอกสารนโยบายกับโค้ดจริงที่ใช้งาน

## การแก้ไข

คืนเงินให้ผู้ซื้อที่ได้รับผลกระทบพร้อมค่าชดเชย ปิดการซื้อขายในตลาด resale สำหรับงานที่เหลือเวลาน้อยกว่า 24 ชั่วโมงด้วยมือชั่วคราว

## Follow-up

implement เงื่อนไขหมดอายุเร็วขึ้นใกล้วันงานให้ตรงตามที่ระบุใน [[business-logic/synthetic-event-ticketing/resale-listing-expiry-policy]] จริง แล้วเพิ่ม test ยืนยันว่าโค้ดตรงกับนโยบายที่เขียนไว้ทุกข้อ
