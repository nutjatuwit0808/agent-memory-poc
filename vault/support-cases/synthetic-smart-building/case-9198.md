# Case 9198 — วาล์วน้ำเย็นเปิด-ปิดถี่ผิดปกติหลังปรับ Deadband แคบเกินไป

## สรุปเคส

ทีมซ่อมบำรุงสังเกตว่าวาล์วน้ำเย็นของโซนชั้น 20 เปิด-ปิดถี่ผิดปกติ (short cycling) เสี่ยงต่ออายุการใช้งานของวาล์วเอง

## การตรวจสอบ

ตรวจ metric ของ [[structure/synthetic-smart-building/module-hvac-controller]] พบว่า `ZONE_DEADBAND_C` ของโซนนี้ถูกปรับจาก 1.0 เหลือ 0.3 ระหว่างการทดสอบ tuning เมื่อสัปดาห์ก่อนแต่ไม่ได้ปรับกลับ

## สาเหตุ

deadband ที่แคบเกินไปทำให้ระบบตีความความผันผวนเล็กน้อยของอุณหภูมิ (จากการเปิดประตูเข้าออกปกติ) เป็นการหลุด deadband ตลอดเวลา สั่ง damper และวาล์วปรับใหม่ทุกครั้งที่อุณหภูมิขยับแม้แค่ 0.3-0.4 องศา

## การแก้ไข

ปรับ `ZONE_DEADBAND_C` กลับเป็น 1.0 ตามค่ามาตรฐาน วาล์วหยุด short cycling ทันที

## Follow-up

เพิ่มขั้นตอนยืนยันคืนค่า config หลังการทดสอบ tuning ทุกครั้งเป็นส่วนหนึ่งของ [[convention/synthetic-smart-building/code-review-checklist]]
