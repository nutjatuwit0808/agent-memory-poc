# Case 3210 — บัตรถูกปฏิเสธซ้ำหลายครั้ง

## สรุปเคส

ลูกค้าพยายามชำระเงินด้วยบัตรเครดิต 4 ครั้งติดกัน ทุกครั้งได้ error "บัตรถูกปฏิเสธ" ลูกค้าถามว่าเป็นปัญหาที่ระบบ PayFlow หรือเปล่า

## การตรวจสอบ

error code ทุกครั้งเป็น `PAYMENT_DECLINED` ไม่ใช่ `PAYMENT_GATEWAY_TIMEOUT` — ตาม [[business-logic/payment-retry-policy]] กรณีนี้ระบบไม่ retry อัตโนมัติเพราะเป็นการตัดสินใจจากธนาคารผู้ออกบัตรโดยตรง ไม่เกี่ยวกับระบบฝั่งเรา

## การแก้ไข

แนะนำลูกค้าให้ติดต่อธนาคารผู้ออกบัตรเพื่อสอบถามสาเหตุ (มักเกิดจากวงเงินไม่พอ หรือธนาคารตรวจพบพฤติกรรมผิดปกติแล้ว block ชั่วคราว) และแนะนำให้ลองวิธีชำระเงินอื่น เช่น พร้อมเพย์

## Follow-up

ลูกค้าลองพร้อมเพย์สำเร็จ ปิดเคส — เตือนใจว่าการพยายามชำระซ้ำหลายครั้งแบบนี้อาจถูกระบบ fraud detection จับตามองด้วยตาม [[business-logic/fraud-detection-rules]] แต่กรณีนี้ไม่ถูก flag เพราะยังไม่ถึง threshold
