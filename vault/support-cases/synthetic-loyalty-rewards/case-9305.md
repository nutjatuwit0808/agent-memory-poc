# Case 9305 — Tier recalculation วนซ้ำไม่หยุดหลัง batch job

## สรุปเคส

หลัง weekly batch tier evaluation รัน CPU ของ [[structure/synthetic-loyalty-rewards/module-tier-calculator]] ไม่ลดลงเลยนานกว่า 2 ชั่วโมง ตรวจสอบพบว่ามีการ re-evaluate tier วนซ้ำสำหรับบัญชีกลุ่มเดิม

## การตรวจสอบ

ตรวจ log พบว่า `evaluateTierChange` publish `tier.downgraded` event ซึ่ง [[structure/synthetic-loyalty-rewards/module-offer-personalizer]] subscribe แล้ว call endpoint ที่มี side effect ทำให้ tier-calculator re-evaluate อีกครั้ง

## สาเหตุ

offer-personalizer เรียก endpoint refresh offer ซึ่ง code path หนึ่งในนั้น trigger tier evaluation อีกรอบ bug เกิดจาก refactor ที่ไม่ได้ตรวจ call graph ครบ

## การแก้ไข

หยุด offer-personalizer ชั่วคราว CPU tier-calculator ลดลงทันที แก้ code path ให้ offer refresh ใช้ read-only endpoint แทน และ rollout ใน batch window ถัดไป

## Follow-up

เพิ่ม circuit breaker ใน tier-calculator สำหรับ account ที่ถูก evaluate เกิน 3 ครั้งใน 1 นาที เพื่อป้องกัน CPU burn จาก loop ที่อาจเกิดขึ้นในอนาคต
