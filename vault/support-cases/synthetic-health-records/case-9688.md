# Case 9688 — ออกใบสั่งยาซ้ำจาก Retry ของแอปแพทย์

## สรุปเคส

ผู้ป่วยรายหนึ่งได้รับใบสั่งยาชนิดเดียวกัน 2 ใบในเวลาไล่เลี่ยกันจากการสั่งของแพทย์คนเดียวครั้งเดียว

## การตรวจสอบ

ตรวจ [[structure/synthetic-health-records/module-prescription-manager]] พบว่าแอปของแพทย์ retry request `issuePrescription` เพราะไม่ได้ response ภายในเวลาที่กำหนด โดยไม่ส่ง idempotency key มาด้วย

## สาเหตุ

ฟังก์ชัน `issuePrescription` ไม่มีกลไก idempotency ใดๆ ทุกครั้งที่เรียกจะสร้างใบสั่งยาใหม่เสมอไม่ว่าจะเป็นการเรียกซ้ำหรือไม่

## การแก้ไข

ยกเลิกใบสั่งยาที่ซ้ำด้วยมือ แจ้งเภสัชกรที่เกี่ยวข้อง แล้ว deploy hotfix เพิ่ม idempotency key ให้ `issuePrescription`

## Follow-up

ตรวจสอบฟังก์ชันอื่นที่มีผลกระทบทางการแพทย์ใน [[structure/synthetic-health-records/module-prescription-manager]] ว่ามีความเสี่ยงขาด idempotency แบบเดียวกันหรือไม่
