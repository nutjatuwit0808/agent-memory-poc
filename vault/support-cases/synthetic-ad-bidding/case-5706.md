# Case 5706 — Creative Renderer ส่งโฆษณาว่างเปล่าหลังเปลี่ยน Template

## สรุปเคส

ทีม creative รายงานว่าแคมเปญวิดีโอหลายตัวแสดงผลเป็นพื้นที่ว่างเปล่าแทนที่จะเป็นวิดีโอ ตั้งแต่หลัง deploy template ใหม่เมื่อเช้า

## การตรวจสอบ

ตรวจ `renderMarkup` ของ [[structure/synthetic-ad-bidding/module-creative-renderer]] พบว่า template ใหม่เปลี่ยนชื่อ placeholder field จาก `{{video_url}}` เป็น `{{media_url}}` แต่ creative metadata เก่าที่ยังไม่ได้ migrate ยังใช้ field เดิม

## สาเหตุ

การเปลี่ยน template ทำโดยทีม creative โดยตรงไม่ผ่านการรีวิวร่วมกับทีม engineering ที่ดูแล renderer เพราะคิดว่าเป็นแค่การเปลี่ยน styling ไม่ใช่การเปลี่ยน field name ที่กระทบ logic

## การแก้ไข

rollback template กลับเวอร์ชันก่อนหน้าทันที แล้วเพิ่ม field mapping layer ที่รองรับทั้งชื่อเก่าและใหม่ชั่วคราวระหว่างที่ migrate metadata เก่าทั้งหมด

## Follow-up

กำหนดว่าการเปลี่ยน template field name ต้องผ่าน code review จากทีม engineering เสมอ ไม่ใช่แค่ทีม creative ปรับเองได้ เพิ่มเข้า [[convention/synthetic-ad-bidding/code-review-checklist]]
