# กฎโปรโมชันโค้ดส่วนลด

## ประเภทโค้ด

- **percentage** — ลดเป็น % ของยอดรวม มี cap สูงสุดต่อออเดอร์เสมอ (ป้องกันส่วนลดบานปลายกับออเดอร์มูลค่าสูง)
- **fixed-amount** — ลดเป็นจำนวนเงินคงที่ เช่น ลด 100 บาท
- **free-shipping** — ยกเว้นค่าจัดส่ง ไม่ลดราคาสินค้า

## กติกาการใช้

- 1 order ใช้โค้ดได้สูงสุด 1 โค้ด ห้ามซ้อนกัน
- โค้ดที่ผูกกับ customer tier บางระดับ (ดู [[business-logic/customer-tier-benefits]]) ใช้ได้เฉพาะลูกค้า tier นั้นขึ้นไปเท่านั้น
- โค้ดหมดอายุคำนวณจาก timestamp ที่ order ถูกสร้าง ไม่ใช่ timestamp ที่ checkout เสร็จสมบูรณ์ — ถ้าลูกค้าเปิดหน้า checkout ค้างไว้นานจนโค้ดหมดอายุระหว่างนั้น order จะถูกสร้างด้วยราคาที่ไม่มีส่วนลด

## การยกเลิก/คืนเงินกับโปรโมชัน

ถ้า order ที่ใช้โค้ดถูกยกเลิกหรือคืนเงิน โค้ดจะไม่ถูกคืนให้ใช้ซ้ำ (ถือว่าใช้ไปแล้ว) ยกเว้นกรณีที่ระบบเป็นฝ่ายผิดพลาด (เช่น bug ทำให้คำนวณส่วนลดผิด) ซึ่งต้องให้ทีม support คืนโค้ดให้ด้วยมือเป็นกรณีไป
