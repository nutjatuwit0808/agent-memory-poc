# Incident Response Runbook

## ระดับความรุนแรง

Sev1 = พลาดตรวจจับอุบัติเหตุจริงหรือคำนวณเบี้ยผิดพลาดกระทบผู้ขับจำนวนมาก, Sev2 = กระทบคะแนนหรือ device provisioning บางส่วน, Sev3 = กระทบเล็กน้อยไม่ถึงความปลอดภัยหรือการเงินโดยตรง

## กรณีที่เกี่ยวกับความปลอดภัย

ทุกเหตุการณ์ที่เกี่ยวข้องกับการตรวจจับอุบัติเหตุผิดพลาด (ทั้ง false positive และ false negative) ต้องยกระดับเป็น Sev1 เสมอและแจ้งทีมความปลอดภัยทันที เขียน postmortem แบบ blameless ภายใน 48 ชั่วโมง
