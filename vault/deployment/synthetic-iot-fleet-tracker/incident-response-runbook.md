# Incident Response Runbook

## ระดับความรุนแรง

Sev1 = ระบบรับ ping ไม่ได้ทั้งหมดหรือแจ้งเตือนผิดวงกว้าง, Sev2 = กระทบลูกค้าบางรายหรือ service เดียว, Sev3 = กระทบเล็กน้อยไม่ถึงลูกค้าปลายทาง

## กรณีข้อมูลผิดพลาดกระทบบิล

ทุกเหตุการณ์ที่กระทบตัวเลขที่ใช้คิดบิลลูกค้า (เช่น mileage ผิดพลาด) ต้องยกระดับเป็นอย่างน้อย Sev2 เสมอและแจ้งทีม billing ทันที ไม่รอให้ลูกค้าโต้แย้งก่อน
