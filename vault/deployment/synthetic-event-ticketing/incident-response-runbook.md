# Incident Response Runbook

## ระดับความรุนแรง

Sev1 = ที่นั่งจองซ้อนหรือบัตรปลอมผ่านการสแกนเข้างาน, Sev2 = กระทบระบบขายต่อหรือ waitlist บางส่วน, Sev3 = กระทบเล็กน้อยไม่ถึงการซื้อขายหรือเข้างานโดยตรง

## กรณีที่เกี่ยวกับหน้างานจริง

ทุกเหตุการณ์ที่กระทบการเข้างานจริง (สแกนผิดพลาด, ที่นั่งจองซ้อน) ต้องยกระดับเป็น Sev1 เสมอเมื่อเกิดในวันงาน เพราะแก้ไขหน้างานยากกว่าการแก้ในระบบมาก
