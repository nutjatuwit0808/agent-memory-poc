# Incident Response Runbook

## ระดับความรุนแรง

Sev1 = เล่นวิดีโอไม่ได้เป็นวงกว้างหรือ live event ล่ม, Sev2 = กระทบบาง feature/บาง publisher, Sev3 = กระทบเล็กน้อยไม่ถึงผู้ชมปลายทาง

## กรณี live event

incident ที่เกิดระหว่าง live event กำลังดำเนินอยู่ยกระดับเป็น Sev1 เสมอโดยอัตโนมัติไม่ว่าผลกระทบจริงจะเล็กแค่ไหน เพราะเวลาที่มีให้แก้ไขจำกัดกว่ากรณี VOD มาก
