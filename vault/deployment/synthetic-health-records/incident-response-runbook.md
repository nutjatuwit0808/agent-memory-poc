# Incident Response Runbook

## ระดับความรุนแรง

Sev1 = ข้อมูลผู้ป่วยรั่วไหลหรือเข้าถึงได้โดยไม่มีสิทธิ์ในวงกว้าง, Sev2 = กระทบบาง service/บางกลุ่มผู้ป่วย, Sev3 = กระทบเล็กน้อยไม่ถึงข้อมูลผู้ป่วยโดยตรง

## กรณีที่เกี่ยวกับ PHI

ทุกเหตุการณ์ที่เกี่ยวข้องกับการเข้าถึง PHI โดยไม่เหมาะสม ต้องยกระดับเป็น Sev1 เสมอและแจ้งทีม compliance ทันที เขียน postmortem แบบ blameless ภายใน 48 ชั่วโมง
